# 방벽 밖 탐사 지도 — 2026-10-20

방벽 도시는 처음부터 컬러로 표시한다. 외부는 짙은 안개에 가려져 있으며 거인별 조사 기록을 확보할 때마다 대응하는 지형이 드러난다. 여섯 기록을 모으면 교관 해독 승인 전에도 지도 전체가 보인다. 최종 해독의 보상은 거인의 제작 장소·최초 목적·폭주 원인과 계승/해방 선택의 공개다.

## 화면과 영역

| 거인 | 탐사 영역 |
| --- | --- |
| 차력 | 남부 보급로 |
| 짐승 | 북동부 고지대 |
| 여성형 | 북서부 숲길 |
| 턱 | 동부 강 유역 |
| 갑옷 | 서부 방벽 외곽 |
| 전퇴 | 남동부 과수원 |

영역은 지형을 따라 굽이치는 곡선으로 나뉜다. 공통 경계와 부드러운 마스크를 사용해 직선 격자와 이음새를 없앴다. 방벽의 성문 돌출부도 초기 공개 윤곽에 포함한다. 기존 1536×1024 지도와 SVG가 동일한 좌표계를 사용하므로 모바일에서도 가림막이 어긋나지 않는다. 지도 이미지를 교체할 경우 `CITY_OUTLINE`과 영역 경계도 새 그림에 맞춰 점검해야 한다.

- 분대원·분대장: 자기 분대의 승인된 조사 기록만 반영한다. 승인 대기 임무는 공개하지 않는다.
- 본부: 적어도 한 분대가 실제 완료한 거인 영역의 합집합을 통합 탐사도로 표시한다. 라운드 수로 탐사 진행을 추정하지 않는다.
- 작전 현황의 지도, 조사 기록의 지도, 최종 작전의 지도는 같은 표시 모듈을 사용한다.
- 발견 시 1.8초 동안 안개가 걷힌다. 첫 입장·새로고침·분대 전환에는 기존 영역을 즉시 복원한다.
- 일반 동기화나 화면 재렌더링은 발견 효과의 시작 시간을 초기화하지 않는다. 동작 줄이기 설정에서는 효과를 생략한다.
- 운영 진행 데이터 형식과 DB 스키마는 바꾸지 않는다. 사이트에는 현실의 활동 도구명·준비물·상세 수행 방법을 추가하지 않는다.

## 파일

- `public/world-map.js`: 방벽 윤곽, 여섯 곡선 영역, 진행 상태 판정, 발견 애니메이션.
- `public/world-map.css`: 지도·안개·진행 표시·모바일 스타일.
- `public/app.js`: 공통 모듈 연결과 입장 완료 후 제어 버튼 상태 갱신.
- `public/index.html`, `dev.mjs`: 신규 스타일·모듈 로딩 및 로컬 경로.
- `tests/world-map.test.mjs`: 승인 전 비공개, 분대 분리, 64가지 기록 조합, 발견 효과 재생 조건.
- `tools/map-preview/`: 실제 작전에 접속하지 않는 독립 지도 리허설. 운영 배포에 포함하지 않는다.

## 독립 리허설

```sh
node tools/map-preview/serve.mjs
```

`http://127.0.0.1:4174/map-preview.html`에서 거인을 원하는 순서로 선택하거나 ‘차례로 탐사하기’를 누른다. ‘출정 전으로’는 데모 지도만 되돌린다. 테스트 Vercel 배포에는 `map-preview.html`, `map-preview.css`, `map-preview.js` 세 파일을 `public/` 경로로 추가하면 같은 리허설을 볼 수 있다. 실제 운영 배포는 기존 허용 목록인 `public/`, `api/`, `lib/`, `package.json`, `package-lock.json`, `vercel.json`만 사용한다.
