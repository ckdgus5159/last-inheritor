# 너의 심장을 바쳐라 · 신조 44게오 — 기획 및 구현 보고

운영·팀장 보고용 / 반전과 결말 포함 / 2026-10-19

## 보고 요약

「너의 심장을 바쳐라」는 진격의 거인의 방벽·조사병단·거인 이미지를 활용해 현장 야유회 활동을 하나의 구조 임무로 연결한 4분대 협동형 웹게임입니다. 참가자는 6개 구역을 순환하면서 협동 활동을 수행하고 조사 기록을 모읍니다. 처음에는 방벽 안의 안전을 지키는 임무로 보이지만, 기록을 연결하면 방벽 밖 제7초소에서 24명이 구조를 기다리고 있었다는 사실이 드러납니다. 마지막에는 즉시 출동, 구조대 조직, 방어와 통신 유지 중 어떤 책임을 먼저 감수할지 토론합니다. 서로 다른 선택을 하나의 구조 노력으로 연결하는 공통 에필로그로 마무리합니다.

## 기획 취지

각 부스 활동에 이야기와 공동 목표를 부여해 참여 동기를 만들고, 활동 후 대화가 이어지게 하는 것이 목적입니다. 초반에는 분대별 점수와 완료 수로 몰입을 만들고, 중반 공동 방어에서는 네 분대 모두의 기여가 필요하도록 전환합니다. 후반에는 흩어진 정보를 검토하고 행동을 결정하게 해 정보 공유·협업·책임의 의미를 되짚습니다.

웹은 공지·시간·이동표·완료 보고·승인·단서·결말을 일관되게 제공하고, 진행자는 현장 활동과 대화를 맡습니다. 모든 분대원이 휴대폰으로 정보를 볼 수 있으며, 대표 분대장만 제출해 중복 보고를 줄입니다.

이 이야기는 사이트를 위해 구성한 체험용 서사이며 원작 애니메이션의 정식 줄거리나 결말을 재현한 것이 아닙니다.

## 전체 구성과 시간

| 단계 | 참가자 경험 | 운영 장치 |
|---|---|---|
| 출정 대기 | 소속 분대 확인, 임무 소개 | 공개 분대원 입장, 분대장 링크, 본부 공지 |
| 1~3R | 거인 구역의 활동과 단서 수집 | 각 12분, 분대별 순환, 완료 보고·승인 |
| 공동 방어 | 초대형 거인 출현, 전 분대 협업 | 8분, 네 역할의 완료 보고·본부 승인 |
| 4~6R | 남은 활동과 기록 연결 | 전체 24개 미션 완료 |
| 최종 작전 | 통신 해독과 구조 방안 토론 | 분대별 암호 해독, 3개 작전 중 하나 확정 |
| 공통 에필로그 | 서로 다른 선택의 의미 공유 | 전 분대 선택 후 관리자 공개 |

정규 라운드는 6 × 12분 = 72분이며, 12분은 활동 8분과 정리·이동 4분을 합친 시간입니다. 공동 방어를 8분 모두 사용하면 여기까지 약 80분입니다. 도입과 해독·토론·마무리는 별도이므로 약 90~100분 편성을 운영안으로 제안합니다. 이는 확정 행사 시간이 아니며 현장 동선과 토론 시간에 따라 조정해야 합니다. 라운드 전환은 관리자가 수동으로 수행합니다.

## 여섯 활동과 단서의 연결

| 거인 구역 | 현장 활동 | 이야기에서 드러나는 정보 |
|---|---|---|
| 차력 | 젓가락으로 콩 옮기기 | 북동쪽 초소의 불빛을 보고도 다른 분대가 확인할 것이라 넘김 |
| 짐승 | 소쿠리에 신발 던지기 | 작은 신호를 중요하지 않다고 여긴 경계병; 일곱 번째 초소 |
| 여성형 | 불완전한 정보로 스파이 추리 | 한 잔만 소금물이라는 전제부터 틀렸음; 잡음 속 구조 요청 |
| 턱 | 밀가루 속 포장 사탕찾기 | 구조 신호 분석과 원정이 미뤄짐; 생존자 스물네 명 |
| 갑옷 | 옷에 붙은 포스트잇을 바람으로 떼기 | 내부를 지키는 일과 외부 사람을 돕는 일을 나누어 생각한 태도에 대한 질문 |
| 전퇴 | 도안에 맞게 강아지 얼굴 종이접기 | 북동쪽 제7초소 / 구조 요청 / 생존자 24명이라는 사실을 종합 |

차력·짐승은 현장 교관의 판단을 반영하도록 본부 승인 및 0~10점 채점을 사용합니다. 나머지 네 구역은 분대장 완료 보고로 각 10점입니다. 여성형은 지목이 맞았는지와 관계없이 완료되며, 정보의 전제를 의심하고 의견을 나누는 경험을 중심에 둡니다. 시음은 희망자만 소량 참여하거나 표정 연기로 대체할 수 있고, 신발은 손으로 낮게 던집니다. 사탕찾기는 밀가루에 얼굴을 넣지 않고 손으로 포장 사탕을 찾으며, 먹기는 활동 후 선택합니다.

현재 기록은 각 미션 완료 시 바로 공개됩니다. 분대별 이동 순서가 달라 일부 분대는 전퇴의 종합 기록을 일찍 받습니다. 따라서 반전 공개 시점을 모든 분대에 동일하게 고정한 구조는 아닙니다. 운영자는 기록을 각 분대 안에서 해석하도록 안내할 수 있지만, 웹에서 분대 간 구두 공유를 막지는 않습니다.

## 스토리라인과 반전

### 도입 — 우리가 믿어온 안전

참가자는 조사병단의 분대원이 되어 여섯 거인 구역을 조사하고 방벽을 지키라는 지령을 받습니다. 표면 목표는 활동을 완수하고 거인을 계승하며 높은 점수를 얻는 것입니다. 처음부터 방벽 주변의 정체불명 신호를 암시해 기록을 읽을 이유를 만듭니다.

### 전개 — 작다고 여긴 신호

기록에는 악의적인 배신보다 일상적인 판단이 쌓입니다. 누군가는 다른 사람이 보고할 것이라 생각했고, 누군가는 자신의 정보가 사소하다고 여겼으며, 조직은 분석과 원정을 다음으로 미뤘습니다. 여성형 미션은 처음 주어진 정보도 틀릴 수 있음을 경험하게 하여 이후 기록을 다시 보게 합니다.

### 중간 사건 — 함께 지켜야 하는 방벽

초대형 거인 출현으로 분대별 활동이 멈춥니다. A 단체줄넘기(방어선 동기화), B 퀴즈(통신 해독), C 종이컵 쌓기(방벽 복구), D 탁구공 릴레이(긴급 보급)가 모두 필요하며, 네 분대 보고와 승인이 모이면 방어가 성공합니다. 실패해도 본부 비상 방어로 이야기를 이어가며, 복구된 통신에서 북동쪽의 미확인 신호를 제시합니다. 성공 조건은 한 분대의 높은 점수보다 네 역할의 연결에 있습니다.

### 반전 — 위협이라고 넘긴 곳에 사람이 있었다

최종 통신의 정답은 **제7초소 / 구조 요청 / 24**입니다. 의미를 알 수 없는 잡음으로 치부했던 것은 생존자들의 구조 요청이었습니다. 길이 전혀 없었던 것이 아니라, 그곳에 아무도 없다고 믿고 확인을 미뤘던 것입니다. 이야기의 초점은 방어 능력의 증명에서, 자신들이 얻은 정보를 바탕으로 누구에게 어떻게 응답할 것인가로 이동합니다.

이 반전은 갑작스러운 배신자 공개보다 방관·정보 단절·확인되지 않은 전제의 누적을 보여주는 데 목적이 있습니다. 각 기록의 단서를 마지막에 다시 해석할 수 있도록 구성했습니다.

어떤 결말에도 절대적인 정답이나 추가 점수를 주지 않습니다. 각 선택의 가치와 비용을 설명하고 분대가 책임을 토론하게 합니다. 전 분대가 같은 작전을 선택해도 진행할 수 있으며, 세 작전이 모두 선택되어야 한다는 조건은 없습니다.

모든 분대가 선택하면 본부가 공통 에필로그를 공개합니다.

> 벽은 끝이 아니었다. 누군가는 먼저 나아가고, 누군가는 길을 만들고, 누군가는 남아서 지켰다. 서로 다른 선택이 하나의 구조가 될 때, 우리의 사명은 계속된다.

개별 엔딩의 차이를 누가 더 옳았는지 평가하기보다, 서로 다른 역할이 공동 목표를 위해 연결될 수 있다는 메시지로 묶습니다.

이번 야유회는 네 분대가 여섯 구역을 순환하며 협동 활동과 기록 수집을 진행하는 이야기형 프로그램입니다. 처음에는 방벽을 지키는 임무처럼 시작하지만, 기록을 모으면 방벽 밖의 24명이 구조를 기다리고 있었다는 사실이 드러납니다. 참가자는 작은 신호를 넘긴 판단과 정보 단절을 되짚고, 즉시 출동·구조대 조직·방어와 통신 유지 중 무엇을 먼저 할지 토론합니다. 각 선택은 장단점을 가지며, 서로 다른 역할이 하나의 구조로 연결된다는 결말을 통해 협업·정보 공유·책임의 의미를 전달하려 합니다. 웹은 안내와 진행 기록을 맡고, 현장 활동과 마지막 회고가 경험을 완성합니다.
