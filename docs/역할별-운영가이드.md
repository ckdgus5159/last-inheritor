> **최신 운영:** 기존 7분/8분 진행과 승인 규칙은 유지하지만, 최종 퍼즐과 결말이 **방벽 내부 / 인류 보호 / 푸른 계곡 → 계승 또는 해방**으로 변경되었습니다. [최신 스토리·배포 체크리스트](2026-10-20-거인기원-두가지엔딩-개편.md)를 따르세요.

> **2026-10-20 적용 사항:** 정규 12분→**7분**(미션과 이동 포함), 공동 방어 8분 유지, 구조 대상 **44분대·생존 30여 명**. A 줄넘기 연속 5회 / B 퀴즈 / C 젠가 / D 티스푼 공 릴레이. 최종 암호는 제7초소 / 구조 요청 / 30여 명. 이전 라운드 및 공동 임무 설명과 충돌하면 [최신 운영/배포 변경 기록](2026-10-20-운영-변경및-배포.md)을 적용하세요.

# 너의 심장을 바쳐라 · 신조 44게오 — 역할별 운영 가이드

운영 사이트: https://last-inheritor.vercel.app

관리자, 분대장, 일반 분대원으로 역할을 나눕니다. 사이트는 현장 활동의 안내·보고·승인·기록 수집·결말 공개를 담당합니다. 실제 활동의 성공 여부는 현장 진행자가 판단합니다.

## 접속 준비

| 역할 | 입장 방법 | 권한 |
|---|---|---|
| 일반 분대원 | 사이트에서 A/B/C/D 선택 → 입장 | 조회 및 분대 토론 참여 |
| 분대장 | 운영자에게 받은 해당 분대 전용 링크 → 분대장으로 입장 | 자기 분대의 미션·방어 보고, 암호 해독, 최종 작전 선택 |
| 관리자 | `/?admin=1`에서 기존 관리자 코드 입력 | 전체 진행, 승인·재도전, 공지, 분대장 교체, 백업·초기화 |

관리자 코드와 분대장 전용 링크는 이 저장소에 포함하지 않습니다. 운영자가 별도로 전달합니다. 같은 브라우저 프로필의 탭은 로그인 정보를 공유하므로 역할을 동시에 테스트하려면 다른 기기·브라우저·프로필을 사용합니다. 동일 브라우저의 여러 시크릿 창도 세션을 공유할 수 있습니다.

분대장은 분대당 한 세션만 지정됩니다. 나가거나 쿠키를 지워도 서버의 분대장 지정은 자동 해제되지 않습니다. 다른 기기로 바꾸려면 관리자에게 지정을 해제해 달라고 요청합니다. 로그인 세션은 12시간입니다.

## 메뉴별 정보

| 메뉴 | 일반 분대원 | 분대장 | 관리자 |
|---|---|---|---|
| 작전 현황 | 본부 공지, 현재 라운드·시간, 우리 분대 점수·완료 수, 현재 미션, 전체 분대 현황, 공동 방어 | 같은 정보 + 현재 미션·방어 완료 보고 | 공지, 전체 완료 수, 분대별 현황·공동 방어 |
| 거인 계승 | 거인별 미션 설명·상태·사진, 현재 배정과 6라운드 이동표 | 같은 정보 + 열린 미션 보고·재도전 | 모든 미션 안내와 이동 계획; 승인은 본부 제어에서 수행 |
| 조사 기록 | 우리 분대가 완료한 미션의 기록; 미완료 기록은 잠금 | 같은 기록을 분대원과 해석 | 모든 기록 열람 가능 |
| 최종 작전 | 개방 전 잠금 안내; 이후 우리 분대의 해독·선택 결과, 결말·공통 에필로그 | 암호 입력, 세 작전 중 하나 확정 | 네 분대의 해독·선택 상태와 공통 에필로그 |
| 본부 제어 | 표시되지 않음 | 표시되지 않음 | 라운드·타이머 제어, 승인·재도전, 방어, 공지, 분대장 교체, 초기화, 최근 작전일지 |

상태는 활성 화면 약 4초, 백그라운드 약 15초 간격으로 갱신됩니다. 일반 분대원은 메뉴를 자유롭게 열람할 수 있지만 보고·해독·선택·본부 지령을 제출할 수 없습니다. 아직 얻지 않은 조사 기록은 참가자 응답에서 제외됩니다. 관리자 화면은 스포일러가 있으므로 참가자 화면과 구분합니다.

## 일반 분대원이 할 일

1. 소속 분대를 선택하고 상단에 `○분대 · 분대원`이 표시되는지 확인합니다.
2. **작전 현황**에서 공지와 현재 구역을 확인하고 현장 활동에 참여합니다.
3. **거인 계승**에서 규칙과 다음 이동 구역을 확인합니다. 완료 보고는 분대장에게 맡깁니다.
4. **조사 기록**에서 새로 열린 단서를 읽고 분대원과 연결해 해석합니다.
5. 초대형 거인 출현 시 **작전 현황**의 자기 분대 방어 임무에 참여합니다.
6. **최종 작전**이 열리면 암호와 구조 방안을 토론하고 분대장이 합의 내용을 제출하도록 합니다.
7. 자기 분대 결말과 공통 에필로그를 읽고 마지막 회고에 참여합니다.

## 분대장이 할 일

1. 전용 링크로 입장하고 `○분대 · 분대장` 표시를 확인합니다.
2. 현재 라운드의 현장 활동을 마친 뒤 **작전 현황** 또는 **거인 계승**에서 보고합니다.
3. **차력·짐승**은 `교관 승인 요청` → 본부 승인 대기 → 계승 완료 순서입니다. 본부가 `재도전 안내`를 보내면 활동을 보완한 뒤 같은 미션에서 다시 요청합니다.
4. **여성형·턱·갑옷·전퇴**는 `미션 완료 보고`로 즉시 완료되며 각 10점입니다. 여성형은 추리 지목의 정오와 관계없이 완료합니다.
5. 완료된 기록을 **조사 기록**에서 확인합니다. 이전 라운드에 열린 미완료 미션은 **거인 계승**에서 다시 선택해 보고할 수 있습니다.
6. 공동 방어 중에는 일반 미션을 중단합니다. **작전 현황**에서 `우리 분대 방어 임무 완료 보고` → 관리자 승인까지 확인합니다.
7. 최종 작전 개방 후 **최종 작전**에서 분대별로 암호를 해독하고 토론 후 작전을 선택합니다. 작전은 한 번 확정하면 바꿀 수 없습니다.
8. 관리자 에필로그 공개 후 같은 메뉴에서 마지막 이야기를 확인합니다.

## 관리자가 할 일

### 시작 전

- **본부 제어**에서 네 분대장 지정과 참가자 접속을 확인합니다. 일반 분대원은 별도 인원 명단·접속자 수로 관리하지 않습니다.
- **전체 공지 → 공지 전송**으로 현장 위치와 시작 안내를 전달합니다.
- 초기화가 필요하면 행사 시작 전에 `데이터 초기화`를 사용합니다. 확인 후 백업 JSON 다운로드를 시작하고 진행·점수·기록·해독·결말·분대장 지정을 초기화합니다. 링크와 관리자 코드는 유지합니다. 백업 이후 다른 진행 변경이 생기면 초기화를 중단하고 다시 시도하도록 안내합니다.
- 초기화 후 분대장은 전용 링크를 다시 열어 입장해야 합니다. 백업 파일에는 내부 세션 식별자가 있으므로 운영자만 보관합니다. 백업 복원은 현재 별도 관리 작업이며 화면의 복원 버튼은 없습니다.

### 1~6라운드

1. `작전 개시 · 1R`로 시작합니다.
2. **교관 승인 대기**의 차력·짐승 요청을 확인하고 0~10점으로 `승인`하거나 `재도전 안내`를 누릅니다. 다른 네 미션은 분대장 보고로 10점 처리합니다.
3. 필요하면 `라운드 일시정지` / `라운드 재개`를 사용합니다. 일시정지 중 참가자는 미션·방어 보고를 할 수 없습니다.
4. 이동 시 `다음 라운드 →`를 누릅니다. 타이머는 매번 12분이며, 8분 활동 + 4분 정리·이동을 뜻합니다. 0초가 되어도 자동 이동하지 않습니다.
5. 다음 라운드는 미완료 미션이 있어도 열 수 있습니다. 다만 최종 작전은 네 분대 모두 6개 미션을 완료해야 열립니다.

| 라운드 | A | B | C | D |
|---|---|---|---|---|
| 1R | 차력 | 짐승 | 여성형 | 턱 |
| 2R | 짐승 | 여성형 | 턱 | 갑옷 |
| 3R | 여성형 | 턱 | 갑옷 | 전퇴 |
| 4R | 턱 | 갑옷 | 전퇴 | 차력 |
| 5R | 갑옷 | 전퇴 | 차력 | 짐승 |
| 6R | 전퇴 | 차력 | 짐승 | 여성형 |

### 공동 방어 — 3R 완료 뒤 권장

1. `초대형 거인 출현`으로 8분 공동 방어를 한 번 발령합니다.
2. A 단체줄넘기 / B 퀴즈 / C 종이컵 쌓기 / D 탁구공 릴레이를 현장에서 안내합니다.
3. 분대장들의 방어 완료 보고를 기다린 뒤 **교관 승인 대기 → 방어 임무 승인**을 누릅니다.
4. 네 분대 모두 승인되면 자동으로 성공 처리되고 일반 미션을 재개할 수 있습니다. 방어 소요 시간은 정규 라운드에 보전됩니다.
5. 제한시간이 지났거나 진행을 마쳐야 하면 `비상 방어로 종료`를 누릅니다. 시간 종료만으로 자동 전환되지 않습니다. 비상 방어도 이야기와 다음 라운드를 이어갈 수 있습니다.

### 최종 작전과 종료

1. 6R, 전체 완료 수 **24/24**, 공동 방어 종료를 확인합니다.
2. `최종 작전 개방`을 누릅니다. 완료 조건이 부족하면 서버가 거부합니다.
3. **최종 작전** 메뉴에서 네 분대의 암호 해독과 작전 선택 상태를 확인합니다. 정답과 결말은 [기획 보고서](기획-보고서.md)에 있습니다.
4. 네 분대 모두 선택한 뒤 **본부 제어 → 공통 에필로그 공개**를 누릅니다.
5. 참가자와 각 선택의 이유를 나누고 회고합니다. 점수는 분대당 최대 60점이며, 결말 선택에는 정답·오답 점수를 매기지 않습니다.

## 인수인계와 재접속

- 분대장 기기 변경: **본부 제어 → 분대장 교체 → 해당 분대 해제** → 새 기기에서 해당 전용 링크로 입장. 진행 기록은 유지됩니다.
- 새 게임: **본부 제어 → 데이터 초기화 → 지령 실행** → 백업 보관 → 분대장 재입장 → 작전 개시.
- 새로고침·로그아웃은 진행을 초기화하지 않습니다. 데이터는 서버에 저장됩니다.
- 버튼이 비활성화되면 역할, 일시정지, 공동 방어 진행 여부, 이미 보고·승인된 미션인지 확인합니다.
- 이 사이트는 한 행사 상태를 공유합니다. 여러 행사를 동시에 분리 운영하는 기능은 없습니다.
