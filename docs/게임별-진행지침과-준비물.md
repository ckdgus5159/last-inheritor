# 너의 심장을 바쳐라 · 신조 44게오 — 게임 진행지침과 준비물

2026-10-19 변경안 적용. 4개 분대의 순환 순서·스토리 단서·최종 암호·세 결말은 유지하고 현장 게임을 교체했습니다. 아래 횟수·거리·수량은 바로 운영할 수 있도록 정한 기본값이며 현장 시연 후 시작 전에 통일해 안내하세요.

차력·짐승은 목표를 다 못 채워도 실제 결과에 해당하는 점수로 승인하면 기록이 열리고 다음 단계로 진행됩니다. 나머지 게임은 현장 완료 기준을 확인한 후 분대장이 보고합니다. 차력·짐승의 점수는 자동 계측하지 않습니다.

### 간단한 세팅과 인수인계

- **콩집기:** 빈 그릇과 콩 그릇을 약 20cm 간격으로 놓습니다. 모두 한 번 이상 참여하도록 순서를 정합니다. 분대가 바뀔 때 콩을 시작 그릇으로 돌려놓습니다. 콩은 먹지 않습니다.
- **신발 던지기:** 소쿠리 앞 공간을 비우고 옆에서 진행합니다. 발로 차거나 사람 쪽으로 던지지 않습니다. 소쿠리 안에 멈춘 경우만 성공입니다. 분대 시작 전에 거리를 통일합니다.
- **여성형:** 진행자용 컵 표시를 하고 참가자에게는 내용을 숨깁니다. 여러 잔을 소금물로 준비할 수 있지만 소량·자발적 시음만 진행합니다. 원치 않는 사람은 물이나 표정 연기로 참여합니다. 컵을 참가자끼리 돌려 마시지 않습니다.
- **사탕찾기:** 얼굴·입을 밀가루에 넣거나 가루를 불지 않습니다. 손으로 포장 사탕을 찾은 뒤 손을 씻고 포장을 벗겨 원하는 사람만 먹습니다. 참가자가 바뀌면 쟁반을 정리하고 새 포장 사탕을 넣습니다. 밀가루 활동을 피해야 하는 참가자는 별도 쟁반의 종이 조각 속 포장 사탕찾기로 대체합니다.
- **포스트잇:** 피부나 얼굴이 아닌 옷 위에 붙입니다. 손으로 떼거나 몸을 털지 않습니다. 얼굴을 가까이 대지 않고 번갈아 도전합니다. 바람 불기가 어려운 참가자는 접은 종이로 부채질하는 대체 참여를 허용합니다.
- **종이접기:** 사이트 **거인 계승 → 전퇴 거인 → 도안 보기**로 열거나 인쇄합니다. 눈·코 그림의 미적 완성도는 채점하지 않습니다. 귀 2개와 접힌 코가 보이면 완료입니다.

## 초대형 거인 공동 미션 — 네 구역 동시 진행

기존처럼 8분 안에 네 분대가 자기 구역 임무를 수행하고, 분대장이 보고한 뒤 본부가 승인합니다. 네 분대 모두 승인되어야 공동 방어가 성공합니다. 정규 미션을 멈춘 동안 진행하므로 정규 구역의 빈 탁자를 재사용할 수 있습니다.

| 분대 | 게임 / 이야기 역할 | 기본 성공 기준 | 준비물 |
|---|---|---|---|
| A | 단체줄넘기 / 방어선 동기화 | 돌리는 2명 + 뛰는 인원(기본 4명)이 연속 3회 성공 | 긴 줄넘기 1개, 넓고 평평한 공간 |
| B | 퀴즈 풀기 / 통신 해독 | 공식 문제 영상에서 진행자가 고른 1문제의 답과 이유 설명. 영상 사용이 어려우면 아래 예비 문제 사용 | 휴대폰·태블릿 또는 문제 인쇄물, 메모지, 펜 |
| C | **추가 제안: 종이컵 쌓기** / 방벽 복구 | 컵 15개를 5·4·3·2·1단으로 쌓고 손을 뗀 채 3초 유지 | 종이컵 15개 + 여분 5개, 평평한 탁자 |
| D | **추가 제안: 탁구공 릴레이** / 긴급 보급 | 컵에서 컵으로 공을 전달해 도착 컵에 3개 확보 | 종이컵 D분대 인원수 + 1개, 탁구공 3개 + 여분 2개 |

종이컵 쌓기는 탁자에 컵만 올리면 시작할 수 있고, 탁구공 릴레이는 컵을 든 채 한 줄로 서면 됩니다. 특별한 장비나 설치가 필요하지 않습니다.

- 줄넘기는 참여 인원에 맞게 줄 길이와 뛰는 인원을 조절합니다. 걸리면 바로 멈춥니다. 뛰기 어려운 사람은 줄 돌리기·횟수 확인을 맡을 수 있습니다.
- 릴레이는 공을 손으로 집어 넘기지 않습니다. 떨어진 공만 출발 컵에서 다시 시도하며 이미 도착한 공은 유지합니다.
- 퀴즈는 3분 뒤 진행자가 힌트를 주고, 정답뿐 아니라 설명을 확인합니다. 시간이 끝나면 관리자가 `비상 방어로 종료`해야 하며 자동 종료되지 않습니다.

### 예비 문제 — 방송 인용이 아닌 별도 작성 문제

참가자에게 아래 문제만 보여주세요.

> A·B·C 상자 중 딱 한 곳에 보급품이 있다. 세 표지 중 참인 것은 하나뿐이다.
>
> A의 표지: 보급품은 B에 있다.
>
> B의 표지: 보급품은 B에 없다.
>
> C의 표지: 보급품은 A에 없다.
>
> 보급품은 어느 상자에 있는가? 이유도 설명하라.

**진행자용 정답: A.** A에 있으면 거짓·참·거짓으로 하나만 참입니다. B에 있으면 참·거짓·참, C에 있으면 거짓·참·참으로 두 개가 참이 되어 조건을 만족하지 않습니다.

힌트 1: A와 B의 표지는 서로 반대이므로 둘 중 하나는 반드시 참입니다.
힌트 2: 전체에서 참이 하나뿐이면 C의 표지는 거짓이어야 합니다.

이 정답은 참가자 사이트 응답에 넣지 않습니다. 진행자가 답과 설명을 확인한 뒤 B분대 보고를 승인합니다.

## 통합 준비물 체크리스트

아래는 **전체 24명, 분대당 6명**을 가정한 구입 예시입니다. 실제 참가자 수를 P, D분대 인원을 D라고 하면 소비성 물품은 해당 수에 맞춰 조정합니다. 생존자 수 24라는 스토리 설정이 실제 참가자 정원을 뜻하지는 않습니다.
