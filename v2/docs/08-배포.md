# 독립 배포·환경변수

GitHub `feat/field-ops-v2`, Vercel `last-inheritor-v2`에만 반영합니다. 기존 main·last-inheritor 프로젝트와 운영 도메인은 변경하지 않습니다. V2 디렉터리만 배포 소스 루트로 사용합니다. 정적 출력은 public, API는 api/ops.js, 런타임은 Node 22 이상입니다.

필수 서버 환경변수:

| 이름 | 용도 |
|---|---|
| FIELDOPS_SESSION_SECRET | V2 전용 세션 서명·분대장 링크 키 |
| FIELDOPS_ADMIN_CODE | V2 관리자 입장 코드 |
| FIELDOPS_DB_SECRET | V2 DB 게이트웨이 인증 |
| FIELDOPS_SUPABASE_URL | Supabase 프로젝트 주소 |
| FIELDOPS_SUPABASE_KEY | publishable API 키 |
| FIELDOPS_FEMALE_RULE | 관리자 전용 특별 진행 안내 |

값은 Vercel 프로젝트 설정에만 저장하고 GitHub·문서·배포 로그에 쓰지 않습니다. 관리자 코드는 프로젝트 환경변수 화면에서 확인합니다.

DB는 동일 Supabase 프로젝트의 **field_ops_v2** 비공개 스키마, `public.fieldops_v2_gateway` RPC를 사용합니다. V1의 app_private·game_gateway와 별도입니다. live와 rehearsal 행, epoch별 QR/보너스 고유 제약으로 중복 지급을 막습니다. 직접 테이블 접근은 RLS·권한 회수로 거부합니다.

신규 설치는 database/schema.sql 템플릿에 새 비밀키의 SHA256과 두 initialState JSON을 채워 실행합니다. **이미 설치된 환경에 재실행하지 않습니다.** 기존 V1 SQL은 실행하지 않습니다.

상태 동기화는 2.5초 폴링입니다. 타이머는 서버 시각과 마감시각을 받아 계산합니다. API 상태 응답은 캐시하지 않습니다. Vercel에 Git 자동 배포를 연결하지 않은 경우 코드 업로드 배포가 필요합니다.
