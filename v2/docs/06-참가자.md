# 분대장·분대원

**분대원:** 분대 선택 → 일반 분대원으로 입장. 작전 현황의 시간·현재 미션·순위·QR 잔여량을 확인합니다. 거인 토벌에서 계승 진행률·획득 능력을, 전투 결과에서 전과를 확인합니다. QR을 발견하면 분대장에게 스캔을 요청합니다.

**분대장:** 입장 화면에서 **분대장 → 소속 분대 선택 → 분대장 코드 입력 → 작전본부 입장** 순서로 들어갑니다. 분대장 코드는 본부 관리자에게 안내받습니다. 영문 대소문자·공백·하이픈은 구분하지 않습니다. 현재 미션을 마치면 **미션 완료 보고**를 한 번 누르고 본부 승인을 기다립니다. 최초 보고시간은 서버에 기록되므로 다시 눌러도 갱신하지 않습니다.

**보너스 현황 → 보급품 수색 현황 → QR 스캔**을 누르고 카메라를 허용합니다. 보급품 QR을 비추면 추가 버튼 없이 자동으로 선착순 확정됩니다. 대기·일시정지·보스전·작전 종료 및 결과 발표 후에도 QR 확보와 점수 획득이 가능합니다. 분대당 최대 4개 제한은 유지됩니다. 로그인한 브라우저 안에서 카메라가 열리므로 분대장 접속이 유지됩니다. 인식·닫기·화면 이탈 시 카메라는 종료됩니다. 권한을 거부했다면 브라우저 사이트 설정에서 카메라를 허용하고 다시 스캔합니다. 보너스는 보너스 현황 메뉴에 표시됩니다. 웹게임 시작은 한 번뿐이며, 현장 지령은 운영실에서 확인받습니다. 남은 시간 안에 승인까지 마쳐야 합니다.

기기 변경·퇴장 후에는 현재 코드로 다시 입장합니다. 새 기기로 입장하면 이전 기기의 분대장 권한은 해제되고, 점수·보고·QR은 유지됩니다. 코드 분실·분대장 교체 시 본부에 코드 재발급을 요청합니다. 재발급 전 코드와 기존 접속 권한은 사용할 수 없습니다. 일반 분대원은 점수를 변경할 수 없습니다. 공유 기기에서는 퇴장 후 다음 역할로 입장합니다.

보너스가 지급되면 해당 분대의 **분대장과 분대원 모두**에게 팝업이 표시됩니다. 팝업을 닫아도 작전 현황 상단의 추가 지령 카드에서 바로 확인할 수 있습니다. 확인한 팝업은 같은 탭에서 새로고침해도 다시 열리지 않으며, 새 기기로 늦게 입장한 분대원에게는 진행 중인 지령을 알립니다. 다음 보너스는 새 팝업으로 알립니다. 라운드 종료 시 진행 중인 지령은 마감됩니다.

참가자 메뉴는 **작전 현황 / 거인 토벌 / 보너스 현황 / 전투 결과** 네 개입니다. 본부 지령은 작전 현황 맨 위에, 미토벌 거인은 흑백으로 표시됩니다.
