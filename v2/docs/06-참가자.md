# 분대장·분대원

**분대원:** 분대 선택 → 일반 분대원으로 입장. 작전 현황의 시간·현재 미션·순위·QR 잔여량을 확인합니다. 계승 도감과 전투 결과는 언제든 볼 수 있습니다. QR을 발견하면 분대장에게 스캔을 요청합니다.

**분대장:** 전달받은 전용 링크로 입장합니다. 현재 미션을 마치면 **미션 완료 보고**를 한 번 누르고 본부 승인을 기다립니다. 최초 보고시간은 서버에 기록되므로 다시 눌러도 갱신하지 않습니다.

QR 스캔 후 **보급품 확보**를 누르면 선착순 확정됩니다. 보너스는 보급·보너스 메뉴에 표시됩니다. 웹게임 시작은 한 번뿐이며, 현장 지령은 운영실에서 확인받습니다. 남은 시간 안에 승인까지 마쳐야 합니다.

기기 변경·분대장 교체가 필요하면 본부에 재지정을 요청합니다. 일반 분대원은 점수를 변경할 수 없습니다. 공유 기기에서는 퇴장 후 다음 역할로 입장합니다.
