# 여섯 거인 운영

| 거인 | 활동 | 준비물 | 보너스 최초 보고 기본 제한 |
|---|---|---|---|
| 차력 | 젓가락으로 콩 옮기기 | 콩, 젓가락, 그릇 | 4분 |
| 짐승 | 신발 던져 소쿠리로 받기 | 신발, 소쿠리 | 4분 |
| 여성형 | 소금물 마신 사람 표정으로 찾기 | 컵, 음용수, 소금 | 3분 |
| 턱 | 밀가루 속 사탕 찾기 | 밀가루, 포장 사탕, 쟁반 | 4분 |
| 갑옷 | 얼굴 포스트잇 입김으로 떼기 | 포스트잇 | 3분 30초 |
| 전퇴 | 팀원마다 다른 종이접기 | 색종이, 쉬운 도안 | 4분 30초 |

각 부스는 방법 시연 → 수행 → 부대장 보고 → 본부 승인 순서입니다. 6점은 참여·미흡, 8점은 부분 성공, 10점은 완전 성공입니다. 구체적인 수량은 미확정이므로 **본부 제어 → 게임 설정 → 거인별 판정 기준**에서 현장 리허설 후 정합니다.

여성형의 특별 진행규칙은 **관리자 화면의 비공개 운영 안내**를 확인합니다. 참가자에게 사전에 공개하지 않습니다. 본부 승인도 정답 자체를 요구하지 않습니다.

짧은 안전 확인: 신발 던지는 방향과 관람선을 구분하고, 밀가루를 들이마시지 않도록 진행합니다. 음식·음료 참여가 어려운 사람에게는 현장 대체 동작을 안내합니다. 준비 수량은 실제 인원과 재사용 여부에 맞춰 정합니다.

부대별 부스는 `(부대번호 + 라운드 − 1) mod 6`으로 정합니다. 같은 라운드의 중복 방문은 없고 각 부대는 모든 부스를 한 번씩 방문합니다.
