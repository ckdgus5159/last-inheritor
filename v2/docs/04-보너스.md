# 보너스미션 6종

본부는 **최초 보고시간 충족 + 기본 10점 승인 + 같은 라운드 미지급 + 라운드 진행 중**일 때 선택적으로 지급합니다. 승인 지연은 자격을 늦추지 않습니다. 건너뛰어도 같은 라운드 내에 나중에 지급할 수 있습니다. 서버가 종류를 무작위로 정하고 부대별 중복을 최소화합니다.

| 미션 | 기본 규칙 | 확정 |
|---|---|---|
| 감각의 10초 | 9.90~10.10초에 정지 | 브라우저 측정·서버 확인 / +3 또는 0 |
| 10초 연타 | 10초 동안 35회 이상 | 서버가 시간·중복 입력 확인 / +3 또는 0 |
| 단체사진 | 랜덤 지령대로 촬영 | 운영실에서 화면 확인 후 성공·실패 |
| 운영실 룰렛 | +3·+1·0·−1 동일 25% | 관리자 실행, 서버 1회 추첨 |
| 지정 인물 | 조건 확인·동의 후 함께 방문 | 운영실 성공·실패 |
| 물병 세우기 | 3회 중 1회 성공 | 운영실 성공·실패 |

사진은 서버에 업로드하지 않습니다. 인물 조건은 옷·소품 등 외관상의 일반 조건만 사용합니다. 타이머 성공 범위·연타 횟수·물병 기준은 본부 설정에서 조절할 수 있습니다.

모든 결과는 **라운드 종료 전에 제출·승인까지** 완료해야 합니다. 웹게임은 한 번 시작하면 새로고침해도 재시작할 수 없습니다. 전송 실패 시 측정 결과만 다시 전송할 수 있으며, 중복 점수는 지급되지 않습니다. 현장 미완료는 시간 종료로 남습니다.
