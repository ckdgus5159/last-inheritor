- [ ] 실제 휴대전화에서 입장·완료 보고·QR 카메라 스캔

브라우저 입력 측정은 개발자 도구로 조작될 가능성을 완전히 제거하지 못합니다. 서버는 역할·단일 도전·경과시간·입력 간격·마감·중복 지급을 검증합니다. 공정한 현장 협력 게임을 전제로 하며, QR 촬영·공유도 완벽히 차단하지 못합니다.

시간 마감 뒤 현장 승인 소급은 허용하지 않습니다. 미수행 토벌은 0점이며, 기본 승인 누락은 보고가 있는 과거 라운드를 점수 정정 화면에서 처리할 수 있습니다. 동점은 공동 순위입니다. 음향과 사진 영구 저장은 없습니다.
