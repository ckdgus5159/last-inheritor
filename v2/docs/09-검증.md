# 검증·제한사항

자동 검증 범위: 순환 충돌, 보고·승인 권한, 최초 보고, 점수·도감·랭킹, 보너스 시간 경계·10점 조건·중복 지급, QR 발행·동시성·4개 제한, QR+보너스 동시 인정, 마감 후 차단, 타이머·연타·룰렛, 상한·하한, 보스전, 분대장 해제, 데이터 초기화·리허설 격리입니다.

`npm test`는 실제 게임 전이와 API 핸들러를 검증합니다. `node scripts/browser-check.mjs`는 Chromium 입장 폼 360·390·768·1440·1890px 정렬, 모바일·PC 4개 메뉴, 계승 통합·흑백 표시·본부 지령 위치, 분대장·분대원 보너스 알림·타 분대 격리·새로고침·늦은 입장·마감, 보고·승인·보너스·QR 출력·리허설을 검사합니다. 최신 실행 결과와 배포 검증 기록은 RELEASE.md를 확인합니다.

`node scripts/admin-check.mjs`는 관리자 360·390·768·900·1440·1890px 레이아웃과 승인 버튼 줄바꿈, QR 12개 연속 활성화·전체 설정·위치 저장, 메뉴·초안·선택·체크·입력 초점 유지, 이전 조회 응답의 덮어쓰기 방지, 중복 클릭 차단, 오류 후 재시도, 실운영·리허설 분리, 6라운드 보고·점수·보너스·보스·결과 발표를 검증합니다. 두 브라우저 검증은 외부 운영 DB를 변경하지 않는 격리된 API 저장소를 사용합니다. 미니게임 중 메뉴를 이동해도 진행을 유지하는지 검사합니다.

`node scripts/captain-check.mjs`는 PC·모바일 코드 입력·관리자 확인·직접 저장·새로고침 유지·다른 분대 초안 유지·중복 거절·복사 대체 동작·숨기기, 잘못된 분대 코드, 재발급 전 코드, 보고·QR 확보, 재입장·기기 변경, 기존 기기 차단, 리허설 코드 분리를 검증합니다. API 테스트는 코드 조회 권한·시도 제한·동시 로그인·초기화 후 무효화도 확인합니다.

현장 확인 항목:

- [ ] 실제 휴대전화에서 입장·완료 보고·QR 카메라 스캔
- [ ] 공원 이동통신·화면 밝기·배터리·12장 인쇄 품질
- [ ] 부스별 6·8·10점 기준 합의
- [ ] 분대장 4대와 관리자 기기의 권한 분리

브라우저 입력 측정은 개발자 도구로 조작될 가능성을 완전히 제거하지 못합니다. 서버는 역할·단일 도전·경과시간·입력 간격·마감·중복 지급을 검증합니다. 공정한 현장 협력 게임을 전제로 하며, QR 촬영·공유도 완벽히 차단하지 못합니다.

시간 마감 뒤 현장 승인 소급은 허용하지 않습니다. 미수행 토벌은 0점이며, 기본 승인 누락은 보고가 있는 과거 라운드를 점수 정정 화면에서 처리할 수 있습니다. 동점은 공동 순위입니다. 음향과 사진 영구 저장은 없습니다.
