# 관리자 빠른 사용법

- 입장 화면에서 **본부 관리자** 선택 → Vercel의 `FIELDOPS_ADMIN_CODE` 값 입력.
- 분대장 링크 발급 → 각 분대장에게 자기 링크만 전달. 교체 시 **분대장 재지정** 후 새 링크 발급.
- 준비: 판정 기준과 시간 설정 → QR 출력·설치 → 독립 리허설.
- 진행: 작전 개시 → 보고가 들어온 카드에서 **6·8·10점** → 자격 충족 시 **보너스미션 지급**.
- 현장 보너스는 성공·실패 한 번 클릭. 룰렛은 운영실에서 실행.
- 라운드 종료 → 다음 라운드. 3R 종료 후에는 초대형 거인 출현을 먼저 실행.
- 보스: A 줄넘기 5회 / B 논리퀴즈 / C 젠가 5개 / D 티스푼 탁구공 릴레이. 성공마다 해당 분대 승인.
- 6R 뒤 작전 종료 → 최종 결과 발표. 급하면 중도 종료도 가능.

상단에는 현재 단계에서 필요한 작전 버튼만 표시합니다. 중도 종료와 조기 발표는 **작전 종료 · 결과 발표** 안에 있습니다. 분대 승인 카드는 화면 폭에 맞춰 1·2·4열로 배치됩니다. 공지와 보스전은 지원 영역에서 처리합니다.

**QR 12개 관리 및 인쇄**는 개별 활성화·위치 저장 후에도 펼친 상태를 유지합니다. 전체 활성화·비활성화도 가능합니다. 활성화는 사용 가능 여부만 바꾸며, 이미 획득한 QR을 다시 지급하거나 점수·토큰을 초기화하지 않습니다.

화면 갱신 후에도 펼친 메뉴, 작성 중인 공지·설정·위치, 선택값과 스크롤을 유지합니다. 실운영·리허설·분대 미리보기의 초안은 서로 분리됩니다. 초안은 현재 페이지 메모리에만 있으므로 새로고침·퇴장하면 사라집니다. 처리 중에는 변경 버튼을 잠그며 실패 시 안내를 확인하고 다시 시도할 수 있습니다.

점수 오류는 **게임 설정·판정 기준·점수 정정**을 펼쳐 수정합니다. 기본점수·QR·보너스·벌점은 각각 정정 가능하며 변경 전후 총점은 자동 기록됩니다. 10점 미만으로 정정하면 그 라운드의 보너스는 취소됩니다.

초기화는 자동 백업을 먼저 내려받고 확인 후 실행합니다. 백업 이후 데이터가 바뀌면 초기화를 거절합니다. 초기화 대상은 상단 표시의 V2 실운영 또는 리허설뿐입니다. V1 초기화 기능과 연결하지 않습니다.
