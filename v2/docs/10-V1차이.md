# V1 → V2

| V1 | V2 |
|---|---|
| 조사 기록·단서·기원 미스터리 | 거인 토벌 점수·계승 도감 |
| 지도 복원·최종 퍼즐 | QR 수색·보너스 6종 |
| 계승·해방 엔딩 | 최종 순위·전투 훈장·공동 승전보 |
