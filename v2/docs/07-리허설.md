# 관리자 1대 기기 리허설

1. 관리자 로그인 → **독립 리허설 열기**. 노란 상단에 리허설 표시를 확인.
2. 관리자 화면에서 작전 개시.
3. 상단 가상 화면에서 A부대장 선택 → 거인 토벌 → 완료 보고.
4. 관리자 복귀 → 10점 승인 → 보너스 지급. 6·8점도 시험하면 자격이 생기지 않음.
5. 가상 부대장 → 보너스 현황 → 웹게임 또는 현장 지령 확인.
6. **가상 QR 스캔 시험**으로 QR 확보. 같은 QR 재요청·4개 제한은 자동 테스트와 운영 QR 관리로 확인.
7. B/C/D부대장도 전환하여 보고·승인. 일반 부대원 미리보기에서는 보고가 불가능한지 확인.
8. 라운드 종료·다음 라운드로 3R까지 진행 → 보스 출현·성공 승인 → 4~6R.
9. 작전 종료 → 최종 결과 발표 → 훈장과 합산 점수 확인.
10. 리허설 초기화 → 실운영으로 돌아가기. 실운영의 점수·QR이 그대로인지 확인.

리허설도 서버에 별도 저장하므로 새로고침 후 다시 들어가 이어갈 수 있습니다. 모든 관리자 기기는 같은 리허설 상태를 공유합니다. 실제 부대장 세션이나 참가자 데이터는 사용하지 않습니다.
