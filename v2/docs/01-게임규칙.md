# 게임 규칙·점수

4개 분대(A~D), 분대당 6명. 정규 6라운드×7분과 3R 뒤 공동 보스전 8분입니다. 입장·안내·발표를 합쳐 약 60분을 목표로 합니다.

| 항목 | 점수 |
|---|---|
| 기본 토벌 | 거인당 6·8·10점, 미수행 0점 / 최대 60 |
| QR | 일반 1점×6개, 희귀 2점×6개 / 분대당 최대 4개·8점 |
| 보너스 | 분대당 라운드별 최대 1회, 성공 최대 +3 / 최대 양수 18 |
| 인정 추가점수 | QR+보너스 양수 합산 최대 20 |
| 벌점 | 룰렛 −1을 별도 차감 |

`최종 = max(0, 기본 + min(20, QR + 보너스 양수) − 룰렛 벌점)`, 최대 80점.

QR과 보너스는 같은 라운드에 동시에 가능합니다. 0초가 되면 QR·보너스 신규 지급·제출·현장 승인이 마감됩니다. 다음 라운드 전환은 자동으로 하지 않습니다. 일시정지 시간은 재개 시 보전합니다.

점수가 같으면 공동 순위·공동 우승입니다. 별도 임의 타이브레이커를 적용하지 않습니다. 보스전은 협동 이벤트로 랭킹 점수에 포함하지 않습니다.
