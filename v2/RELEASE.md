# V2 구현·배포 검증

## 최신 디자인 개정 — 2026-10-21

사용자 요청에 따라 생성 이미지 9개를 제거하고, V1에서 사용하던 실제 애니메이션 장면 12개로 교체했다. 온라인 공식 자료를 대조하고 이미지 출처 페이지를 추가했다. V1의 짙은 녹색·올리브색, 상단 헤더, 모바일 하단 메뉴, 각진 패널과 사진 중심 작전 현황을 적용했다.

규칙/API 테스트 24개, 모바일·PC 브라우저, 교체한 사진 12개 로딩, 보고·승인·QR 인쇄·미니게임 검증이 통과했다. 실제 V2 배포에서도 디자인·사진·이미지 출처 페이지를 확인했다. V1과 V2 실운영·리허설 DB 데이터 해시는 변경 전후 동일하다.

아래는 초기 V2 배포 당시의 검증 기록이다. 이미지에 관한 초기 기록은 위 개정 내용으로 대체한다.

## 실제 통과한 검증

1. V2 게임 규칙 20개와 API 4개 자동 테스트 통과.
2. 실제 Chromium에서 390px 모바일 5개 메뉴, 1440px 관리자, 보고·승인·보너스 지급·QR 확보, 12장 QR HTML 다운로드 검증.
3. 실제 10초 타이머와 15초 연타 UI를 실행하고 서버 확정을 확인. JavaScript 오류 없음.
4. 실제 배포 사이트에서 일반 분대원·관리자 입장, 모바일 가로 넘침 없음, 창작 장면 9개 로딩, 예상하지 않은 JavaScript·CSP 오류 없음. 미입장 상태의 초기 API 401은 정상 인증 동작.
5. 실제 Vercel API와 Supabase에서 리허설 6라운드 전체를 실행. 동시 동일 QR은 한 팀만 성공, 분대 4개 제한·초과 시 미소모, 보너스 6종·보스 HP·최종 점수·초기화 검증.
6. 전 과정 후 V2 실운영과 리허설은 출정 대기(0R), QR 미사용 상태. 테스트는 실운영 점수를 변경하지 않음.
7. Supabase 보안 검사 지적 사항 없음. V1 DB version 108, 데이터 SHA256 `cc763b451507c09a114eb7b473a36c928813818893c93d7f9e67dd057dc8725f` 유지.
8. V1 런타임 파일·main·운영 도메인을 변경하지 않음. V1 도메인은 기존 배포를 계속 가리킴.

루트 테스트가 브라우저·배포 검증 파일을 자동 탐색하던 문제는 V2 scripts 디렉터리로 분리해 해결했다. 본부·참가자 상태는 2.5초 폴링하며 서버 시각으로 마감을 판정한다.

## 행사 전 남은 운영 준비

- 본부의 거인별 6·8·10점 현장 기준 확정
- 분대장 4명 지정·전용 링크 전달
- 실운영 QR 12장 출력·설치와 실제 휴대전화 카메라 확인
- 공원의 실제 이동통신·밝기·배터리 확인

코드·DB·배포 연결의 미완료 항목은 없다. 외부 애니메이션 캡처의 이용허락이 확인되지 않아 자체 제작 장면을 사용한다. 브라우저 입력 조작·QR URL 공유를 완전히 방지하는 시스템은 아니며 현장 협력 게임을 전제로 한다.
