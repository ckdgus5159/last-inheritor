# V2 구현·배포 검증

## 분대장 코드 직접 설정 — 2026-10-21

본부 제어의 「분대장 코드 설정」에서 분대별 새 코드 입력·저장을 지원한다. 영문·숫자 4~20자(숫자만 가능), 대소문자·공백·하이픈은 구분하지 않는다. 다른 분대·관리자와 중복은 거절한다. 코드를 변경하면 이전 코드·세션을 무효화하고 기록은 보존한다. 동일 코드 저장은 세션을 유지한다. 동시·오래된 저장은 epoch와 세대로 차단한다. 사용자 지정 코드는 AES-256-GCM으로 암호화하고 일반 상태 응답·이력에 넣지 않는다. 기존 자동 코드도 직접 변경하기 전까지 유지하며 DB 마이그레이션·초기화는 없다.

검증: V2 규칙 22개·API 11개, 루트 7개 테스트 파일 통과. 직접 저장·암호화·조회 비공개·권한·입력 경계·중복·동시 저장·새 코드 입장·이전 세션 해제·동일 코드 재저장·모드 분리·재발급·초기화·기록 보존을 확인했다. Chromium 360·390·900·1440px에서 직접 저장·다른 분대 초안 보존·새로고침 유지·중복 거절·새 코드 입장·이전 기기 차단·보고·QR 확보를 통과했다. JavaScript 오류 없음.


## 분대장 코드 입장 — 2026-10-21

전용 링크 입장을 분대별 코드 입장으로 교체했다. 관리자만 코드를 확인·복사할 수 있으며 분대별 재발급은 이전 코드·세션을 무효화한다. 코드 재입장은 최신 기기로 조작 권한을 이전하고 점수·보고·QR을 보존한다. 대소문자·공백·하이픈 차이를 허용한다. 코드는 게임 epoch에 묶여 전체 초기화 시 변경된다. 기존 환경변수와 DB 구조를 그대로 사용하며 마이그레이션이 필요 없다.

검증 결과: V2 규칙 22개·API 8개, 루트 7개 테스트 파일과 분대장·기존 참가자·관리자 브라우저 검증 통과. 네 분대 코드·분대 일치·잘못된 코드·기존 링크 거절, 관리자 전용 조회, 최초 입장·동일 기기 재입장·기기 변경·동시 입장, 코드 재발급·초기화 후 무효, 실운영·리허설 코드 분리, 시도 제한, 참가자 정보 비공개, PC·모바일 코드 입력·복사 대체 동작·숨기기·보고·QR 흐름을 확인했다. JavaScript 오류 없음.


## 관리자 화면 재배치·갱신 오류 수정 — 2026-10-21

- 작전 제어를 현재 단계에 맞는 버튼으로 정리하고 분대 승인 카드·공지·보스전·QR·설정을 구분했다. 모바일 1열, 중간 폭 2열, 넓은 관리자 화면 4열이며 점수 승인 문구가 줄바꿈되지 않는다.
- 서버 응답 때 전체 DOM을 교체하면서 QR 메뉴가 닫히던 문제를 해결했다. 모든 관리 메뉴의 펼침, 수정 중인 공지·QR 위치·설정, 체크·선택·초점·스크롤을 현재 화면 범위에서 유지한다. 실운영·리허설·역할별 초안은 분리하고 퇴장 시 지운다.
- QR 전체 활성화·비활성화를 추가했다. 이미 사용된 QR·수집 점수·토큰은 유지한다.
- 이전 조회 응답이 새 변경을 덮어쓰는 문제, 연속 클릭 중 변경 요청이 조용히 사라지는 문제, 실패한 화면 전환, 미니게임 도중 메뉴 이동 시 조작 화면이 사라지는 문제를 수정했다. 통신 실패·제한시간 초과를 안내하고 변경 처리 중 중복 조작을 막는다. 오래된 라운드·보너스에 대한 승인도 서버에서 거절한다.

검증: V2 규칙 22개·API 4개와 루트 7개 테스트 파일 통과. Chromium 관리자 360·390·768·900·1440·1890px, QR 12개 연속 조작·전체 설정·위치 저장, 초안과 입력 상태 유지, 지연 조회·중복 클릭·503 후 재시도·모드 격리, 6라운드 보고·승인·보너스·보스·발표 통과. 기존 참가자 화면·알림·QR 인쇄·실제 10초/15초 미니게임 회귀 검증 통과. JavaScript 오류 없음. 운영 데이터 변경 없이 격리된 저장소에서 수행했다.

## 입장 문구·타이포그래피 — 2026-10-21

입장 문구를 「조사병단의 사명!!! / 너의 심장을 바쳐라」로 변경했다. Black Han Sans 기반 제목·전투 연출, Noto Sans KR 기반 본문·조작 UI, Rajdhani 기반 점수·타이머로 역할을 나눴다. OFL 라이선스를 포함하고 WOFF2를 직접 제공한다. 본문 글꼴은 자주 쓰는 문자와 나머지 한글을 나누어 필요한 파일만 불러오며 현대 완성형 한글 전체를 보존한다. 브라우저 검증은 세 서체와 드문 한글의 실제 로딩, PC·모바일 폭·기존 게임 흐름을 확인한다.

## 참가자 화면 정리·분대 전체 알림 — 2026-10-21

- 행사명은 **심장을 바쳐라 / 신조 44게오**. 입장 폼을 V1처럼 최대 370px로 묶어 라벨·입력창·버튼을 정렬하고 불필요한 영문·소개 문구를 제거했다.
- 참가자 메뉴는 작전 현황, 거인 토벌, 보너스 현황, 전투 결과 네 개. 계승 진행률·능력·완성 기념 연출은 거인 토벌에 통합했다.
- 본부 지령을 작전 현황 최상단에 배치했다. 전체 토벌 진행 통계와 참가자용 준비물·승인 절차 안내를 제거하고 거인별 특징·도전 목표를 보강했다. 미토벌 거인은 알아볼 수 있는 흑백 사진으로 표시한다.
- 보너스 지급 시 해당 분대장·분대원 모두에게 팝업을 표시한다. 확인 뒤에도 작전 현황에 진행 중인 지령 카드가 남는다. 같은 탭에서 확인한 지령은 새로고침 후 중복 팝업을 띄우지 않으며, 다른 기기의 늦은 입장자에게는 알린다. 새 보너스는 별도로 알린다. 다른 분대의 지령은 전달하지 않는다.
- 알림은 본부 연결 중 2.5초 폴링으로 동기화한다. 라운드 종료 시 활성 카드·팝업을 닫는다. 무음, 키보드 닫기·초점 이동·움직임 최소화를 지원한다.

검증: 게임 규칙/API 24개 및 루트 7개 테스트 파일 통과. Chromium에서 입장 폼 360·390·768·1440·1890px 정렬과 폭, PC·모바일 네 메뉴 가로 넘침, 실제 사진 12개, 계승 통합·흑백 표시·상단 지령, 분대 전체 알림·타 분대 격리·확인 후 새로고침·늦은 입장·마감, 보고·승인·QR 12장·10초/연타 게임·리허설 격리 통과. JavaScript 오류 없음. 브라우저 화면 증거는 CI의 v2-browser-evidence 아티팩트에 보관한다.

## 애니메이션·V1 디자인 개정 — 2026-10-21

사용자 요청에 따라 생성 이미지 9개를 제거하고, V1에서 사용하던 실제 애니메이션 장면 12개로 교체했다. 온라인 공식 자료를 대조하고 이미지 출처 페이지를 추가했다. V1의 짙은 녹색·올리브색, 상단 헤더, 모바일 하단 메뉴, 각진 패널과 사진 중심 작전 현황을 적용했다.

규칙/API 테스트 24개, 모바일·PC 브라우저, 교체한 사진 12개 로딩, 보고·승인·QR 인쇄·미니게임 검증이 통과했다. 실제 V2 배포에서도 디자인·사진·이미지 출처 페이지를 확인했다. V1과 V2 실운영·리허설 DB 데이터 해시는 변경 전후 동일하다.

## 실제 통과한 검증

1. V2 게임 규칙 20개와 API 4개 자동 테스트 통과.
2. 실제 Chromium에서 390px 모바일 5개 메뉴, 1440px 관리자, 보고·승인·보너스 지급·QR 확보, 12장 QR HTML 다운로드 검증.
3. 실제 10초 타이머와 15초 연타 UI를 실행하고 서버 확정을 확인. JavaScript 오류 없음.
4. 실제 배포 사이트에서 일반 분대원·관리자 입장, 모바일 가로 넘침 없음, 창작 장면 9개 로딩, 예상하지 않은 JavaScript·CSP 오류 없음. 미입장 상태의 초기 API 401은 정상 인증 동작.
5. 실제 Vercel API와 Supabase에서 리허설 6라운드 전체를 실행. 동시 동일 QR은 한 팀만 성공, 분대 4개 제한·초과 시 미소모, 보너스 6종·보스 HP·최종 점수·초기화 검증.
6. 전 과정 후 V2 실운영과 리허설은 출정 대기(0R), QR 미사용 상태. 테스트는 실운영 점수를 변경하지 않음.
7. Supabase 보안 검사 지적 사항 없음. V1 DB version 108, 데이터 SHA256 `cc763b451507c09a114eb7b473a36c928813818893c93d7f9e67dd057dc8725f` 유지.
8. V1 런타임 파일·main·운영 도메인을 변경하지 않음. V1 도메인은 기존 배포를 계속 가리킴.

루트 테스트가 브라우저·배포 검증 파일을 자동 탐색하던 문제는 V2 scripts 디렉터리로 분리해 해결했다. 본부·참가자 상태는 2.5초 폴링하며 서버 시각으로 마감을 판정한다.
